# Образцы голосов XTTS

Поместите сюда два файла, не добавляя их в Git:

- `user.wav` — голос пользователя;
- `assistant.wav` — голос ассистента.

Рекомендуется 10–30 секунд чистой речи одного человека без музыки, эха,
посторонних голосов и сильного фонового шума. Используйте только собственный
голос или запись человека, который явно разрешил клонирование.

Если файлы находятся в другом месте, укажите абсолютные пути через
`XTTS_USER_REFERENCE` и `XTTS_ASSISTANT_REFERENCE` в `.env.local`.
