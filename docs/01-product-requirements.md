# Продуктовое ТЗ

## 1. Назначение

Chat Video Studio — локальное настольное приложение для создания видеоконтента
из диалогов с ИИ. Приложение импортирует диалог, озвучивает выбранные реплики,
синхронно раскрывает текст и воспроизводит разговор внутри стилизованного окна
браузера с автоматической прокруткой.

## 2. Проблема

Пользователь может сохранить переписку как Markdown, однако создание ролика
вручную требует отдельно записывать озвучку, анимировать сообщения, выравнивать
текст по звуку и настраивать прокрутку. Повторная генерация одной неудачной
реплики обычно приводит к ручному перестроению всего монтажа.

Приложение должно автоматизировать этот процесс и сохранять связь между текстом,
аудио и визуальным клипом на уровне каждой реплики.

## 3. Целевая аудитория

- авторы YouTube Shorts, TikTok и Reels;
- авторы обучающих и объясняющих видео;
- создатели контента о работе с ИИ;
- пользователи, публикующие разборы и инсценировки диалогов.

## 4. Основной пользовательский сценарий

1. Пользователь импортирует `.md` или проектный `.json`.
2. Приложение показывает распознанные реплики и участников.
3. Пользователь исправляет текст и при необходимости делит длинные реплики.
4. Для участников назначаются голоса ElevenLabs либо ручные аудиофайлы.
5. Пользователь генерирует отсутствующую озвучку.
6. Приложение строит таймлайн и синхронизирует раскрытие текста с речью.
7. Пользователь выбирает тему чата и параметры окна браузера.
8. В предпросмотре пользователь находит неудачную реплику и создаёт новый дубль.
9. Новый дубль заменяет активный, последующие клипы автоматически сдвигаются.
10. Пользователь экспортирует MP4 и при необходимости SRT.

## 5. Цели MVP

- получать воспроизводимый проект из Markdown-диалога;
- поддерживать двух и более участников, оптимизируя интерфейс под двух;
- генерировать пользовательские реплики через ElevenLabs;
- принимать готовое аудио для любой реплики;
- хранить несколько дублей без потери ранее оплаченной генерации;
- раскрывать текст по словам в соответствии с аудио;
- автоматически прокручивать виртуальный чат;
- менять оформление без изменения текста и звука;
- экспортировать вертикальное видео 1080×1920, H.264/AAC.

## 6. Не входит в MVP

- извлечение штатного аудио из закрытых внутренних потоков ChatGPT или Gemini;
- клонирование голосов, на которые у пользователя нет прав;
- формулы, интерактивные таблицы и сложная Markdown-вёрстка;
- полноценный нелинейный видеоредактор;
- совместное редактирование и облачный рендеринг;
- автоматическая публикация в социальные сети;
- мобильное приложение;
- параллельные реплики, перебивания и одновременная речь.

## 7. Продуктовые принципы

### 7.1. Недеструктивное редактирование

Новая генерация создаёт новый дубль. Старый дубль не удаляется автоматически.

### 7.2. Детерминированный рендер

При неизменных проекте, ассетах, версии шаблона и параметрах рендера результат
должен иметь одинаковое расположение элементов и длительность.

### 7.3. Локальность

Проекты, переписки и аудио хранятся локально. Во внешние сервисы отправляется
только текст, явно выбранный для генерации речи.

### 7.4. Независимость оформления

Сценарий, аудио и тема являются независимыми слоями. Смена темы не вызывает
повторную генерацию аудио.

### 7.5. Явное происхождение аудио

Для каждого дубля хранится источник: ElevenLabs, импорт или запись. Приложение
не должно обозначать сторонний голос как официальный голос платформы.

## 8. Метрики качества MVP

- успешный импорт не менее 95% файлов, созданных текущими расширениями;
- замена дубля одной реплики не требует ручного сдвига последующих клипов;
- расхождение отображения слова и его начала в аудио не превышает одного кадра
  при наличии корректных таймингов;
- повторный экспорт не вызывает повторных TTS-запросов без действия пользователя;
- проект после закрытия и открытия сохраняет выбранные дубли и оформление;
- типовой ролик до 5 минут экспортируется без пропущенных сообщений.

## 9. Ограничения и допущения

- исходный текст заранее очищен от сложных формул и нестандартных виджетов;
- Markdown поддерживает абзацы, переносы, простые списки, выделение и код;
- один сегмент содержит речь только одного участника;
- для точной синхронизации импортированного аудио требуется alignment;
- пользователь самостоятельно отвечает за права на импортированные голоса и аудио.
