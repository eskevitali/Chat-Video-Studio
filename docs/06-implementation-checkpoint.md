# Контрольная точка реализации

Дата фиксации: 2026-08-31.

## Подтверждённое состояние

- Импорт диалогов из Markdown и JSON.
- Редактирование реплик с инвалидированием устаревшей озвучки.
- Автосохранение и восстановление проекта через локальное хранилище.
- Экспорт и импорт версионированного JSON-снимка.
- История аудиодублей и выбор активного дубля.
- ElevenLabs с отдельными голосами пользователя и ассистента.
- Локальный XTTS v2 с двумя образцами голоса.
- Локальное выравнивание слов через faster-whisper `small`.
- XTTS проверен на NVIDIA GeForce GTX 1080 через CUDA `int8`.
- Пресеты оформления: нейтральный, ChatGPT-подобный и Gemini-подобный.
- Настраиваемые цвета, заголовок и подпись виртуального чата.
- Форматы 9:16, 16:9 и 1:1; масштаб, скорость индикатора набора и FPS.
- Локальный Remotion-экспорт MP4 с кнопкой скачивания.
- Выбор реплики на таймлайне и переход к её началу в видеоплеере.
- Пропорциональная полоса границ клипов и компактная форма волны активного дубля.
- Прослушивание и сравнение всех дублей до смены активного.

Пользователь проверил генерацию XTTS и Whisper-синхронизацию: работает.

## Локальное окружение

- Node запускается из bundled Codex runtime.
- XTTS находится в `.venv-xtts` и исключён из Git.
- Python 3.12.
- PyTorch 2.6.0 + CUDA 12.4.
- `coqui-tts` 0.27.5.
- Transformers 4.57.6 — закреплён из-за несовместимости XTTS с 5.x.
- `faster-whisper` 1.2.1.
- Модель Whisper `small` загружена в локальный Hugging Face cache.
- Модель XTTS загружена, CPML подтверждена пользователем.
- Образцы находятся в `voice-samples/user.wav` и
  `voice-samples/assistant.wav`; файлы исключены из Git.
