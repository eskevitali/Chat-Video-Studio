# Chat Video Studio

Приложение для превращения текстового диалога в синхронизированное видео
с интерфейсом виртуального браузерного чата. Работает в браузере телефона
и десктопа.

## Статус

Хостовая редакция: `https://vchat.lokvita.org` (Docker на KIDer).
Озвучка только через ElevenLabs. API-ключ и Voice ID вводятся в настройках
приложения и хранятся в браузере оператора, не в Git и не в JSON-снимке.

Редактор: импорт Markdown/JSON, автосохранение, таймлайн, дубли, изображения,
темы, кадр 9:16 / 16:9 / 1:1, превью Remotion, экспорт MP4.

Спека хостовой редакции: [docs/08-hosted-mobile-spec.md](docs/08-hosted-mobile-spec.md).
Деплой: [docs/09-kider-deployment.md](docs/09-kider-deployment.md).

## Локальная озвучка XTTS v2

XTTS v2 устанавливается в отдельное окружение `.venv-xtts` и доступен как
альтернативный движок новых дублей. Для завершения первоначальной настройки:

1. Положите чистые WAV-образцы длительностью 10–30 секунд в
   `voice-samples/user.wav` и `voice-samples/assistant.wav`. Альтернативно можно
   указать абсолютные пути `XTTS_USER_REFERENCE` и `XTTS_ASSISTANT_REFERENCE`.
2. Запустите `pnpm xtts:setup` и лично подтвердите условия некоммерческой CPML.
3. Перезапустите `pnpm dev` и выберите «XTTS v2 · локально» в редакторе.

Зафиксированное окружение использует Python 3.12, PyTorch 2.6.0 с CUDA 12.4,
`coqui-tts` 0.27.5 и Transformers 4.57.6. Последняя версия закреплена намеренно:
ветка Transformers 5.x несовместима с текущим XTTS.

Образцы голоса и сгенерированное аудио остаются на компьютере. XTTS не расходует
кредиты ElevenLabs. После генерации WAV локальный `faster-whisper` получает
временные метки слов и сопоставляет их с исходным текстом. По умолчанию используется
многоязычная модель `small`; значение можно изменить через `XTTS_ALIGNMENT_MODEL`.
При ошибке Whisper дубль не теряется — редактор автоматически использует
приблизительные тайминги и явно показывает это возле реплики.

## Запуск прототипа

Требования: Node.js 20+ и pnpm.

```bash
pnpm install
pnpm audio:demo
pnpm test
pnpm dev
```

Если системный `pnpm` отсутствует, сервер можно запустить без установки npm:

```bash
bash run-dev.sh
```

Для открытия Remotion Studio:

```bash
pnpm studio
```

Для рендера вертикального MP4:

```bash
pnpm render
```

Результат сохраняется в `output/prototype.mp4`.

## ElevenLabs

На `vchat.lokvita.org` и в обычном запуске ключ и Voice ID вводятся в блоке
«Настройки». Они остаются в `localStorage` этого браузера.

Для локального `pnpm dev` по-прежнему можно положить запасные значения в
`.env.local` (файл не в Git). Не добавляйте ключ в `project.json`, исходный код,
скриншоты или сообщения.

## Ключевая модель

```text
Реплика чата ↔ активный аудиодубль ↔ визуальный клип
```

Исходный Markdown или JSON импортируется в проект. Пользователь редактирует
реплики, назначает голоса, создаёт и выбирает аудиодубли, настраивает тему чата,
проверяет синхронизацию в предпросмотре и экспортирует MP4.
